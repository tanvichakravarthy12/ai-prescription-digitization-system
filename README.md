# AI Prescription Digitization System

A computer vision and OCR-based system that converts handwritten medical prescriptions into structured digital records.

## Features

- Upload prescription images
- OCR text extraction
- Medicine region detection
- Structured JSON output
- Streamlit web interface

## Tech Stack

- Python
- Streamlit
- OpenCV
- Tesseract OCR
- Transformers (TrOCR)

## Future Work

- Automatic medicine extraction
- TrOCR integration
- PDF generation
- LLM-powered medicine correction
